# Thumbnail Maker

元画像を拡大・縮小せず、16:9 または 9:16 に切り抜いてPNG保存するブラウザツールです。

### [ブラウザで使う →](https://nexustide400.github.io/thumbnail-maker/)

## スクリーンショット

![Thumbnail Makerの画面](assets/screenshot.png)

## 特徴

- 元画像をリサイズせず、16:9／9:16に切り抜き
- ボタンで横長・縦長を切り替え
- スライダーで上下・左右の切り抜き位置を調整
- 透明部分を保ったままPNG保存
- 画像の選び直し・クリアに対応
- 画像のアップロード不要。処理はブラウザ内で完結
- 外部ライブラリ・インストール・ビルド不要
- PC・スマートフォン対応

## 使い方

1. [Thumbnail Makerを開きます](https://nexustide400.github.io/thumbnail-maker/)。
2. 画像をドロップするか「画像を選ぶ」で読み込みます。
3. 横長16:9／縦長9:16を切り替えます。
4. スライダーで切り抜き位置を調整し、「PNGを保存」を押します。
5. 「画像を選び直す」で変更、「画像を消す」で画像をクリアできます。

## ローカルで使う

リポジトリをダウンロードし、フォルダー構成を保ったまま `index.html` をブラウザで開いてください。インストール・ビルド・Webサーバーは不要です。

## 切り抜き仕様

- 元画像のピクセルをそのまま使い、リサイズや透明な余白の追加はしません。
- 元画像に収まる最大の正確な整数ピクセル比率で切り抜きます。16:9では幅が16の倍数、高さが9の倍数です。9:16では逆になります。
- 例：1920×1080 → 横長1920×1080／縦長603×1072。
- 比率を正確に保つため、調整方向以外の端も数px切り抜く場合があります。その方向は中央に配置します。
- 横にはみ出す画像は左右、縦にはみ出す画像は上下に位置を調整できます。
- 比率の切り替え・画像の変更時には切り抜き位置を中央に戻します。
- 16×9または9×16の最小サイズを確保できない画像は、その比率で保存できません。
- 透明部分は保持します。アニメーション画像のアニメーションは保存しません。
- 保存名には比率と出力サイズが入ります。

## ファイル構成

- `index.html`：画面の構造
- `styles.css`：画面デザインとスマートフォン向けレイアウト
- `app.js`：読み込み、切り抜き、PNG保存
- `assets/title-characters.png`：ヘッダーの装飾画像

フォルダー構成を保ったまま `index.html` を開いてください。GitHub Pagesでもそのまま配信できます。

## 技術構成

HTML・CSS・JavaScript・Canvas API。外部ライブラリなし。画像はブラウザ内で処理し、サーバーへ送信しません。
画面装飾に `assets/title-characters.png` を使用します。
